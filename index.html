数据备份 / 恢复

备份包含全部会话、消息、用量连同配置（模型、降价、系统提示），但不含 API Key（避免文件外泄）。在手机和电脑之间用这个 .json 文件搬运即可。
手机端：先把本页放到能联网打开的地方（发文件用手机浏览器打开，或传静态托管拿链接），再「恢复」这个备份。

分支回溯

编辑消息或重新生成时，被作废的后续分支会先自动存一份快照。点任意一条即可回到当时的状态；当前状态也会自动存一份，可以来回切。
每个对话最多保留 8 个快照，最旧的会被挤掉。

载入文档

支持 .txt / .md / .docx（Word 2007+）。只取文字，图片、表格样式会忽略；旧版 .doc 请先另存为 .docx 或 .txt。
放在系统提示里不占对话内容、而且能吃到缓存命中，长期最省；放在消息里更接近官方网页的用法。

在当前浏览器的全部会话里搜提问与回复正文（含思考内容），不区分大小写。点结果可直接跳到那条消息。

导入历史对话

支持两种格式：
① JSON 数组（推荐，来自导出扩展 / 其他客户端）：[{"role":"user","content":"..."},{"role":"assistant","content":"..."}]
② 带角色标记的纯文本 / Markdown：每行开头用「用户：」「助手：」（或 User: / AI:）区分角色。
注：DeepSeek 官方网页端本身没有原生导出按钮，通常需先复制文本或用扩展导出为 JSON / Markdown。导入将作用于当前对话。
